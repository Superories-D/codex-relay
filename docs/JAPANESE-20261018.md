# Japanese interface

Japanese (`ja`) joins Simplified Chinese, Traditional Chinese and English in
Settings → General → Language. Japanese system locales resolve to Japanese when
following the system. An unset preference now follows the system consistently
with native menus and the settings selector.

The Japanese catalog contains all 1,044 existing English-catalog keys, including
chat, tasks, account relay, approvals/questions, Goals, subagents, Git, files,
plugins/MCP, scheduling, settings and native menus. The audit checks static UI
keys and public operation labels; the test checks every interpolation token.
This does not claim localization of arbitrary CLI/server output or every raw
backend exception. User messages, model output, code and file paths remain intact.

Japanese uses Yu Gothic UI / Meiryo font fallbacks when no custom UI font is set.
Several navigation labels are shortened to fit the sidebar. Imported-session
dates now use the selected language instead of hard-coded Simplified Chinese.
