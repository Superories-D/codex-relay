# Desktop 适配与故障恢复（v0.4.0）

这里的 Desktop 指 Windows 官方 Codex 客户端；Relay 自身也是 Electron 桌面工具。官方客户端适配仍需要真机验收，不能把浏览器合成页面测试当作官方客户端兼容保证。

## 操作流程

1. 在「设置」点击「自动检测官方客户端」。检测 Microsoft Store 包与已知本地安装位置；发现多个安装时手动选定一个，再保存。也可以选择 Codex.exe。客户端模式仍需安装 Codex CLI，用于会话准备与额度读取。
2. 添加并核实账户，创建任务，执行方式选择「官方客户端（实验适配）」。先用小型测试项目。
3. 工作台会显示当前准备阶段：获取账户独占权、恢复会话、启动独立实例、连接调试端口、定位任务会话、核实输入、等待执行事件。首次启动如有引导，在受管窗口完成。
4. 用「打开受管客户端」定位独立实例。需要审批或输入时，在该窗口处理。Relay 不会自动回答用户问题或放宽审批权限。
5. 用「检查适配」读取连接、目标会话和可用控件数量。运行时发送按钮为 0 可能正常；停止按钮应唯一。诊断不会点击按钮或读取草稿正文。
6. 暂停或额度耗尽时，发送停止操作，等待实际终止记录。之后确认原进程退出，保存刷新后的凭据，才能使用下一个账户恢复同一会话。

## 如何避免错发与重复

- 新建任务有独立 CODEX_HOME 与 Electron profile。普通客户端的已有主会话可通过「接入已有会话」迁入；交接先结束明确选择的原实例，后续使用独立受管实例，详见 [接入指南](EXISTING-SESSIONS.md)。
- 启动先生成并持久化线程，固定实际模型，确认 bootstrap 进程退出后才启动 GUI。
- 可按线程控件、包含完整 thread ID 的链接或精确会话标题定位；发送前再次检查目标会话。
- 检查会话、比对草稿、检查按钮唯一且可用、点击按钮在同一次页面脚本执行中完成。停止按钮也绑定目标会话；不会因为页面换到其他任务而停止错误任务。
- 非空的其他草稿不覆盖。完全相同的任务草稿允许重试填入，避免重复文本。
- 发送前持久化 `desktopSubmissionPending`。如果点击后断连、崩溃或尚未收到 task_started 就被暂停，恢复提示会说明发送结果不确定，并带上原始目标，要求检查既有结果。收到真实新 turn ID 后才清除标记。
- 该标记不能保证所有外部操作恰好执行一次。Codex 仍需检查文件和会话，重要外部操作继续使用审批。

## 典型情况

| 界面/错误 | 含义与处理 |
| --- | --- |
| 等待额度恢复 | 任务未完成。到期重新向服务器核实，确认可用后自动恢复。 |
| 已暂停 | 人工暂停优先于自动轮换。点击继续任务才恢复。 |
| 定位任务会话 | 检查受管窗口是否仍在首次运行引导；确认窗口中能看到 Relay 任务标题。 |
| 未找到唯一空白输入框 | 保留了已有草稿，或选择器匹配多个控件。检查受管窗口，不要清除其他任务内容。 |
| 发送/停止按钮无法确认 | 客户端版本的 DOM 可能改变，或当前会话已切换。保留任务后在设置中修正选择器并恢复。 |
| 未检测到新 task_started | 没有证明本次任务在受管目录内启动；不能标记运行成功。检查客户端是否支持隔离目录。 |
| 多个候选页面 | 独立实例内有多个页面，无法唯一定位。关闭该实例额外窗口后恢复。 |
| 最近连接确认停止更新 | 本地 CDP 心跳每约 10 秒一次，单次最多等待 8 秒。断连会保留任务并进入处理流程。长时间没有模型输出本身不是卡死证据。 |
| 检查并恢复 | 原进程停止未能确认，队列保护性冻结。恢复时仍要验证实例；按钮不会绕过验证。 |

默认控件选择器覆盖英文与中文的一些常见标签，**不是所有发布版本的通用接口**。当前没有官方稳定的 Desktop 自动操作协议；CDP 关闭或 DOM 改变可能需要更新适配。默认定位最多等待约 10 秒；启动阶段有多个独立超时，因此总等待可能超过某一阶段标称值。

## Windows 适配细节

- 优先识别 Codex Store 包，保留 ChatGPT 包兼容路径；独立 exe 可手动配置。
- 使用绝对系统 PowerShell/taskkill 路径，参数按 Windows 命令行规则引用，支持空格和中文目录。
- PowerShell 文件采用 UTF-8 BOM，输出显式 UTF-8，兼容 Windows PowerShell 5.1。
- 回执用 nonce 绑定本次启动，用 PID、exe 路径、profile、进程创建时间核对归属，减少 PID 复用风险。
- 额度探针单实例运行；若探针进程未确认关闭，账户独占权不释放。
- Relay 初始窗口和最小尺寸受屏幕工作区限制；窄窗口重排统计卡、账户卡与任务详情，弹窗可滚动且支持键盘焦点循环。
