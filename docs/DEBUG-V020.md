# v0.2.0 Desktop 与响应性调试记录

日期：2026-10-14。以下结论限定于已执行的 Linux 构建、模拟边界测试和真实 Chromium 检查。

| 问题或风险 | 修改 | 验证 |
| --- | --- | --- |
| 每次输出都深复制全部状态 | 状态通知最多每 100ms 一次，输出限长，总日志限量 | 1000 条长日志测试，只发一次快照且保留量不超过 50 万字符 |
| 未换行协议输出持续累积 | UTF-8 分帧器在解析前限制 8MiB，RPC/IPC/CDP 请求数量与缓冲上限 | 分片中文、超长未终止帧、错误 JSON 形状、命令洪泛回归 |
| 账户逐个探测推迟可执行任务 | 已知可用账户优先调度；空闲每轮最多探测一个账户 | 首账户不可用但第二账户可用、每轮探测预算测试 |
| 并发落盘排队增长 | 合并尚未开始的状态写入，成功后才兑现相应保存请求 | 控制 rename 阻塞，核对两个后续快照合并；写入失败后能继续保存 |
| 全局 busy 锁住无关操作 | 按任务/账户跟踪操作，其他页面仍可浏览；显示操作阶段与后台连接 | 待定额度刷新期间新建任务、表单和导航浏览器检查 |
| 同账户不同操作共享 Promise 导致返回类型错误 | 同类操作去重，不同命令冲突明确拒绝；不复用额度结果给模型列表 | 实际 React 页面中刷新未结束时读取模型，正确提示且页面不崩溃 |
| 发送/停止时用户已切到其他会话 | 同次 DOM 执行核对目标会话、草稿、唯一按钮；路由不接受查询参数引用 ID | 真实 Chromium 用错会话、改草稿、禁用控件验证拒绝操作 |
| 点击发送后断连，无法判断是否已开始 | 发送前保存待确认标记；真实 task_started 清除；恢复提示包括原始目标与进度核对 | 单元测试和完整启动模拟确认落盘先于点击 |
| 默认模型只在 bootstrap 选择 | 启动 GUI 前将实际选定模型写回隔离 config.toml | 完整启动测试在 PowerShell 启动边界读取文件核对 |
| 准备中暂停、探针关闭失败 | 取消标记与阶段检查；及时关闭 bootstrap；保留探针句柄与独占权 | 暂停不启动 Desktop；探针不能停止时不释放账户 |
| 受管窗口识别不够严格 | receipt 创建时间加入 PID、路径、profile 校验；新增窗口前置操作 | 静态审阅，真实 Windows 行为仍待验收 |
| 小屏幕窗口超出工作区 | 主窗口尺寸按工作区限制；窄布局重排；焦点受控的滚动弹窗 | 860/1000/1440px 五页面无横向溢出，Escape 关闭与表单保留检查 |

完成标准未放宽：额度错误和耗尽事件优先于看似正常的终止；停止请求 ACK 不代替终止记录；全账户耗尽继续等待；旧进程停止不确定时冻结队列。

本版 98 项 Vitest 测试通过，实际页面和 Cdp 浏览器回归通过。尚未运行真实 Windows GUI/DPAPI/Store 启动、实际账户登录轮换和额度耗尽流程；不宣称不存在所有卡死或兼容问题。已保留可复现脚本、故障提示和真机验收项。
