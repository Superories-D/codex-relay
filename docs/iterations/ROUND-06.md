# 第六轮：可恢复、不会误覆盖磁盘内容的文件编辑

内置编辑器现在按真实文件路径保存未落盘草稿和编辑基线指纹。离开文件、切换预览或重启后，可显式恢复或丢弃。存在旧草稿时先处理再开始新编辑，避免新内容悄悄覆盖旧草稿；保存早期请求完成时，也不会删除等待期间新输入的内容。

保存失败保持编辑区与草稿可见。磁盘版本变化后可以重新读取并对照，恢复冲突草稿必须显式确认后才允许保存。重新读取本身不会替换草稿。Ctrl+S 走相同检查。持久化失败会保留当前窗口内存副本、显示下载副本操作，关闭窗口触发未保存提醒。返回文件列表会恢复之前所在目录。

后端文本预览返回 SHA256 与真实路径。`workspace.write` 在旧的 mtime 检查之外支持 expectedHash，按真实文件串行保存并再次读取版本；同一大小、同一时间戳但内容被替换也会拒绝。UTF-8 字节数限制在写入前验证。保存仍使用原有项目边界和 UTF-8 编码检查；其他程序在检查后继续写入不受本进程锁约束。

验证：17/17 项专项测试通过，覆盖安全的目录恢复、内存回退、草稿损坏、较早保存不删除后续输入、真实同时间戳文件替换、真实并发保存、字节限制、目录边界及原有 Desktop 读写行为。TypeScript 检查通过。生产界面恢复/冲突流程纳入综合浏览器 QA。
