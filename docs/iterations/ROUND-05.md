# 第五轮：可以定位和浏览的项目文件工作区

项目文件面板从展开目录树改为有范围的目录浏览器。路径面包屑支持直接返回任意父级，方向键/Home/End 选择文件，Enter 打开，向右进入目录，Backspace/向左返回父级。可显示点文件，偏好保留；刷新保留当前范围。

搜索匹配当前目录及子目录的文件名和相对路径，复用既有工作区边界检查，不遍历 `.git`、依赖缓存等服务端已排除目录。输入防抖、项目/目录切换与新查询取消旧结果。搜索最多检查 150 个目录或返回 200 项；目录读取失败与服务端单目录上限均明确说明结果可能不完整，不会假装搜索穷尽。列表超过 150 项分批显示。

验证：`npx vitest run tests/file-browser.test.ts` 4/4 通过，覆盖子树范围、点文件、目录错误、取消、目录和结果上限及 Windows 路径面包屑。生产界面浏览器验证由综合 QA 执行。
