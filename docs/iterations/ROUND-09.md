# 第九轮：会话证据检索

搜索从简单分页升级为消息定位工作台：按角色检索、跨页前后结果导航、详情中的逐处关键词导航、上下文复制与当前页摘要复制。方向键和 Enter 导航，Shift+Enter 返回；输入法确认不触发结果切换。

搜索结果与会话、关键词、角色和实际分页游标绑定。查询变化时旧结果立即隐藏，过时响应不能覆盖新查询。前一页使用已访问的真实游标，不假设固定页长。搜索失败和详情读取失败分别提示，均可原地重试。

高亮采用字面匹配，不解释正则或 HTML。NFKC 匹配保留原文偏移，因此全角、连字和组合字符也能正确标记；高亮限制为 1000 个原文位置，消息文本不因高亮限制而截断。详情保留服务器提供的长内容提示。

验证：4 项纯逻辑测试覆盖 Unicode 偏移、正则／HTML 字面量、数量边界和游标上下文；生产渲染器浏览器流程由 scripts/qa/iterations-ten.cjs 集成验证。未发送模型请求。
