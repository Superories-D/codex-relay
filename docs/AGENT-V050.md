# Agent 客户端 v0.5.0（2026-10-17）

Windows x64、Node.js 24.13.0、Electron 44.7.0、Codex CLI 0.162.1。改动与构建产物保留在本地，未推送远程。协议依据为本机 CLI 生成的类型与 [官方 app-server 文档](https://learn.chatgpt.com/docs/app-server)。

## 使用

打开 `release/Codex-Relay-Portable-0.5.0-x64.exe`，或运行安装版 `Codex-Relay-Setup-0.5.0-x64.exe`。原有本机账户与任务沿用 `%APPDATA%\Codex Relay`。本机真实任务仍依赖设置中的 Codex CLI；移动项目后应重新确认路径。

- 侧栏按项目显示对话，提供搜索、新聊天、重命名、归档、历史导入和账户入口。
- 同一会话连续追问，运行时可排队下一条或立即补充指令。停止按钮会等待原轮次和进程停止；账户接力沿用已有线程。
- 消息、工具执行、文件变更、计划、推理摘要分别展示。完整聊天保存为独立 JSONL，分页读取，不受诊断日志容量限制。
- 附件支持本地图片与文件引用。命令、文件写入、额外权限和 MCP 输入请求可在界面处理。
- 输入框下方选择模型和思考强度。模型名称、可用档位、默认档位均读取实际账户的 `model/list`。切换到不支持原强度的模型时采用新模型默认值；重置恢复当前模型默认强度。排队消息保留发送时所选模型与强度。
- 会话信息提供目录、线程和轮次信息；支持审查未提交修改、复制独立会话、查看 CLI 能力与配置。
- 已处理的斜杠命令包括 `/new`、`/clear`、`/model`、`/status`、`/permissions`、`/resume`、`/fork`、`/archive`、`/review`、`/compact`、`/skills`、`/mcp`、`/config`、`/help`。未知命令会提示，不作为普通提示词发送。

## 导入 CLI 与 Desktop 历史

默认扫描 `CODEX_HOME` 及用户 `.codex` 下的 `sessions`、`archived_sessions`，读取 `session_index.jsonl` 中的标题。也可添加其他本地 Codex 数据目录。扫描没有旧接口的 60 条上限，按线程去重，逐条报告失败。

导入创建独立线程与会话副本，保留消息和工具记录，恢复最后一个 `turn_context` 的模型与思考强度。源会话处于写入中时只复制起始时完整的 JSONL 记录；源文件被替换或截断则报错。原会话文件不被改写。原来用于运行中接管的“接入已有会话”仍在任务管理界面，与静态历史导入是两个入口。

仅存在云端、WSL 或远程系统中的记录，需要先提供其本地可读 Codex 数据目录。依赖 Desktop 专属工具、父线程或外部历史基底的记录可阅读，但会标注无法直接在 CLI 续跑；子代理记录须从主会话继续。

## CLI 操作范围

日常 Agent 工作使用真正的 CLI `thread/start`、`thread/resume`、`turn/start`、`turn/steer`、`turn/interrupt` 与 `review/start`；后端保留账户轮换、额度核实、进程恢复与审批控制。

“CLI 能力与配置”提供 32 个公开协议操作模板，覆盖模型、Skills、MCP 状态/登录/资源/工具、插件/应用、配置、权限配置、Hooks、目标、Git 变更与非交互命令执行。参数可在 JSON 编辑器中调整；可用性取决于 CLI 版本及账户权限。配置属于该会话的隔离 Codex 目录。非交互命令沿用当前沙盒，最多 60 秒。需交互审批的操作应通过聊天发起。

这版尚未完整复刻原生 CLI TUI 的全部控件、交互终端、语音/实时能力及 Desktop 私有工具。并行任务、云端接管和原生 Desktop 工具执行也不在当前实现范围内。不能将此版本描述为“支持 CLI 所有操作”。
