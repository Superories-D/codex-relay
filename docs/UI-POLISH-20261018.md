# Workspace UI polish — 2026-10-18

This change continues from v0.6.14 (`2bbe4d3`) in response to the crowded,
unfinished workspace appearance and oversized composer. Package version remains
0.6.14. This is a verified source change, not a new packaged release.

## Implemented

- Neutral dark/light surfaces replace the green sidebar tint; navigation,
  selection, borders and controls share theme tokens.
- Narrower sidebar and closer project spacing leave more room for conversation.
  Project chevrons, counts and current-project emphasis clarify the hierarchy.
- Header separates project and conversation title. Clicking the title renames the
  conversation; advanced CLI operations remain in the conversation menu.
- Conversation and composer share a maximum width and responsive side insets.
  Tool summaries and reasoning rows are quieter and more compact; all details
  remain expandable. Generic tool activity no longer claims to be a shell command.
- Composer starts with one 44px text row and measures **85 CSS px overall** in
  the checked layouts. It expands with text up to a 200px text area, shrinks when
  text is removed, and recalculates wrapping on width changes. Global input/select
  margins no longer add unwanted vertical space. Model/effort and send controls
  use more compact spacing and consistent icons.
- Completed sidebar import reports start collapsed. Active work, warnings and
  failures reveal details; start, cancel and custom history-source selection
  remain available. Account management is a native keyboard-accessible button.
